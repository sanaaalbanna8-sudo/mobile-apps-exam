# تحدي معمارية تطبيقات الهواتف الذكية — BTEC IT

اختبار تفاعلي (20 سؤالاً) لطالبات تقنية المعلومات حول خصائص تطبيقات الأجهزة المحمولة ومنطق عملها.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة والرسوم (SVG) |
| `style.css` | التصميم (Glassmorphism / Bento) والتجاوب |
| `script.js` | منطق الاختبار + بنك الأسئلة + الإرسال إلى Google Sheets |
| `Code.gs` | كود Google Apps Script لاستقبال النتائج في الجدول |

## الإعداد (3 خطوات)
1. **Google Sheets:** افتحي جدولاً جديداً ← Extensions ← Apps Script ← الصقي محتوى `Code.gs` ← شغّلي الدالة `setup` ووافقي على الأذونات.
2. **النشر:** Deploy ← New deployment ← Web app ← Execute as: **Me** ← Who has access: **Anyone** ← انسخي الرابط المنتهي بـ `/exec`.
3. **الربط:** افتحي `script.js` والصقي الرابط في السطر:
   ```js
   GOOGLE_SCRIPT_URL: 'https://script.google.com/macros/s/XXXX/exec',
   ```

## الرفع على الإنترنت
- **Netlify:** اسحبي المجلد كاملاً إلى https://app.netlify.com/drop
- **GitHub Pages:** ارفعي الملفات إلى مستودع ← Settings ← Pages ← Branch: main / root.

## ما يُحفظ في الجدول
التاريخ والوقت، اسم الطالبة، الصف، الشعبة، الدرجة من 20، النسبة، التقدير، رقم المحاولة، مدة الحل، الأسئلة الخاطئة، ثم عمود لكل سؤال (`✔ ب` أو `✘ أ ← ب`)، مع التفاصيل الكاملة بصيغة JSON.
> الحروف في الجدول تتبع ترتيب بنك الأسئلة الأصلي (أ، ب، ج) حتى لو خُلطت الخيارات على شاشة الطالبة.

## إعدادات اختيارية (أعلى `script.js`)
- `SHUFFLE_OPTIONS` — خلط ترتيب الخيارات (مفعّل).
- `AUTO_ADVANCE` — الانتقال التلقائي بعد الاختيار (مفعّل).
- `CONFETTI_FROM_PERCENT` — نسبة ظهور الاحتفال (80%).
